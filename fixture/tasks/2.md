# Print the list as JSON lines

## Goal
`stock list --json` prints one JSON object per item, `{"name": ..., "count": ...}`, one per line, so other tools can read it without parsing text.

## Done when
- `python3 -m stock list items.csv --json` prints three lines, each a JSON object with `name` and `count`, in file order.
- Without `--json`, the output is exactly as before.
- Each line parses with `python3 -c 'import json,sys; [json.loads(l) for l in sys.stdin]'`.

## Out of scope
- Reading JSON input.
