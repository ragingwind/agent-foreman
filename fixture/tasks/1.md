# Show only the items there are enough of

## Goal
`stock list` takes `--min N` and prints only the items with a count of at least N.

## Done when
- `python3 -m stock list items.csv --min 10` prints `bolts: 12` and `washers: 40`, and not `nuts`.
- Without `--min`, `stock list` prints every item as before.
- `--min` with a value that is not a whole number is refused with a message and a non-zero exit.

## Out of scope
- Any other change to the output format.
